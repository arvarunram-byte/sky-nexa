1. Executive Overview & Problem Statement

1.1 The Kessler Syndrome & Space Traffic Crisis

Low Earth Orbit (LEO) is experiencing exponential congestion. Over 10,000 active satellites and more than 36,000 tracked space debris fragments larger than 10 cm are currently orbiting Earth at hypervelocities exceeding 27,500 km/h (7.6 km/s). At these velocities, a microscopic paint fleck can puncture a spacecraft's thermal shielding, while a 1 kg metal shard carries the kinetic energy equivalent to a detonating landmine.

Without proactive, real-time collision detection and optimized orbital avoidance maneuvers, cascade collisions—known as the Kessler Syndrome—threaten to render key orbital corridors unusable, directly crippling global telecommunications, weather forecasting, GPS navigation, and defense warning systems.

Core Mission: SKY NEXA provides an end-to-end, visual space situational awareness (SSA) platform that tracks satellites in real time, computes hypervelocity collision risk vectors, calculates propellant-optimized avoidance maneuvers (ΔV), and exports standardized conjunction safety reports for satellite operators.

3. Orbital Mechanics, Physics & Formulas

3.1 Two-Body Keplerian Motion

Each spacecraft's instantaneous orbital velocity $v$ and orbital period $T$ are calculated based on its altitude $h$ above Earth's mean radius $R_E$:

v = √( μ / (R_E + h) )        T = 2π √( (R_E + h)³ / μ )
where μ = G · M_Earth = 3.986004418 × 10^14 m³/s² and R_E = 6,371 km

Orbital planes are constructed in 3D by rotating the orbital ring vector through the spacecraft's inclination angle $i$ and Right Ascension of the Ascending Node (Ω):

N̂ = [ sin(i)·sin(Ω),  cos(i),  sin(i)·cos(Ω) ]

3.2 Hohmann Transfer Collision Avoidance (ΔV Optimization)

When an impending collision or high-risk conjunction is detected in the Simulator Lab, the platform calculates the optimal two-impulse Hohmann Transfer to raise the spacecraft into a safe co-planar circular orbit ($r_2 = r_1 + \Delta h$):

Δv_1 = √(μ/r_1) · [ √( (2·r_2)/(r_1 + r_2) ) - 1 ]
Δv_2 = √(μ/r_2) · [ 1 - √( (2·r_1)/(r_1 + r_2) ) ]
Δv_total = |Δv_1| + |Δv_2|

3.3 Tsiolkovsky Rocket Equation (Propellant Budget)

To provide realistic engineering figures for satellite operators, the required fuel consumption (hydrazine $N_2H_4$ or krypton ion) is determined using the Tsiolkovsky equation:

Δv = I_sp · g_0 · ln( m_0 / m_f )  ⟹  m_fuel = m_0 · ( 1 - e^( -Δv / (I_sp · g_0) ) )
where I_sp ≈ 220 s (monopropellant hydrazine thruster) and g_0 = 9.80665 m/s²

4. Backend Server & Packaging Architecture

4.1 Node.js Micro-Server (serve.js)

Rather than relying on heavy server frameworks (like Express or NestJS) that introduce dozens of megabytes in dependencies, SKY NEXA utilizes a streamlined, native Node.js HTTP server: 

const http = require('http');
const fs = require('fs');
const path = require('path');

// Automatically binds to cloud PORT (Render, Railway, etc.) or default 3000
const PORT = process.env.PORT || 3000;

const MIME_TYPES = {
  '.html': 'text/html',
  '.js':   'text/javascript',
  '.css':  'text/css',
  '.json': 'application/json',
  '.png':  'image/png',
  '.jpg':  'image/jpeg',
  '.svg':  'image/svg+xml'
};

const server = http.createServer((req, res) => {
  let filePath = path.join(__dirname, req.url === '/' ? 'index.html' : req.url);
  const ext = path.extname(filePath);
  const contentType = MIME_TYPES[ext] || 'text/plain';

  fs.readFile(filePath, (err, content) => {
    if (err) {
      res.writeHead(err.code === 'ENOENT' ? 404 : 500, { 'Content-Type': 'text/plain' });
      res.end(err.code === 'ENOENT' ? '404 Not Found' : `Server Error: ${err.code}`);
    } else {
      res.writeHead(200, { 'Content-Type': contentType, 'Access-Control-Allow-Origin': '*' });
      res.end(content);
    }
  });
});

server.listen(PORT, () => console.log(`Sky Nexa server running on port ${PORT}`));
